## C#

A collection of C# programs exploring language fundamentals, object-oriented programming, software design principles, and testability.

### Overview

This repository explores variables, data types, operators, arrays, collections, classes, inheritance, polymorphism, composition, and other core language features. It also includes examples of file handling, extensibility, and writing testable code using separate testing projects.

The repository is organized into independent .NET projects, with each project focusing on a particular concept.

### Topics Covered

- **C# Fundamentals:** Variables, data types, operators, and type conversion
- **Control Flow:** Loops, conditional statements, and basic program execution
- **Arrays & Collections:** Arrays and generic lists
- **Object-Oriented Programming:** Classes, objects, properties, and encapsulation
- **Inheritance & Polymorphism:** Inheritance hierarchies and polymorphic behaviour
- **Composition:** Object composition and dependency relationships
- **Non-Primitive Types:** Classes, structs, and enumerations
- **Indexers:** Implementing and using indexers in C#
- **Strings:** String manipulation and operations
- **File Handling:** Files, directories, paths, and FileInfo operations
- **Extensibility:** Interfaces, logging abstractions, and extensible components
- **Testability:** Writing testable code and separating business logic
- **Unit Testing:** Testing application logic using a separate testing project

### Getting Started

**Prerequisites:** .NET SDK and an IDE such as Visual Studio or Visual Studio Code.

1. Clone the repository:

   ```bash
   git clone https://github.com/naba93980/c-sharp.git
   ```

2. Navigate to the individual project you want to explore:

   ```bash
   cd c-sharp/HelloWorld
   ```

3. Run the project:

   ```bash
   dotnet run
   ```

4. For projects containing a `.csproj` file, you can also build them using:

   ```bash
   dotnet build
   ```

5. For the testing project, navigate to its directory and execute:

   ```bash
   dotnet test
   ```

### Purpose

A hands-on learning repository for building a foundation in C#, understanding object-oriented programming, exploring software design concepts, and developing an understanding of writing maintainable and testable applications.
